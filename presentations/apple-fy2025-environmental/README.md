# Apple FY2025 Environmental Progress Deck

Board & executive sales leadership presentation: how Apple 2030 drives premium positioning, enterprise wins, and supply-chain risk mitigation.

## Open locally

```bash
# from repo root
python3 -m http.server 8765 --directory presentations/apple-fy2025-environmental
```

Then visit `http://localhost:8765`.

## Controls

- `→` / `Space` / swipe left — next slide
- `←` / swipe right — previous slide
- `N` — toggle speaker notes
- `Home` / `End` — first / last slide
- Deep link: `#3` opens slide 3
